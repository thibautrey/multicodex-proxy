# MultiVibe logo package

## Concept

The mark fuses **M** and **V** into one monogram:

- the teal structure represents the multiple providers and accounts handled by MultiVibe;
- the amber diagonal represents the route currently selected by the smart router;
- the rounded geometry matches the existing dashboard UI and remains legible at favicon size.

The logo deliberately avoids a generic cloud symbol. The product is a cloud service, but its distinctive idea is routing many AI providers through one stable interface.

## Primary colors

- Deep background: `#101C19`
- Primary teal: `#147D72`
- Teal on dark: `#55C7B8`
- Accent amber: `#DD984D`
- Amber on dark: `#EFB26F`
- Primary text: `#14231F`
- Muted text: `#6B7D77`

These colors are derived from the current MultiVibe dashboard palette.

## Recommended files

- Website header on a light background: `vector/multivibe-logo-domain-light.svg`
- Website header on a dark background: `vector/multivibe-logo-domain-dark.svg`
- Dashboard/sidebar icon: `vector/multivibe-app-icon.svg`
- Small inline mark without a square: `vector/multivibe-mark.svg`
- Favicon: `favicon/favicon.svg` and `favicon/favicon.ico`
- Apple touch icon: `favicon/apple-touch-icon.png`

The regular wordmark SVGs keep editable text and expect **Inter**. The `-outlined.svg` versions convert the letters to vector paths, so they render identically without requiring the font.

## Minimum size and spacing

- App icon: usable down to 16 × 16 px.
- Horizontal wordmark: keep it at least 150 px wide.
- Clear space: leave at least the width of one logo stroke around the mark.
- Do not recolor only one part of the monochrome version; use the supplied two-color or monochrome assets.
